# MathHub

MathHub is an interactive math practice application built with HTML, CSS, and JavaScript.  
It provides randomized practice questions across multiple areas of mathematics, including arithmetic, fractions, geometry, trigonometry, algebra, and calculus.

The project was designed to make math practice simple and interactive.

# Features

- Interactive topic selection
- Randomly generated questions
- 10 questions per practice session
- Instant answer validation
- Score tracking
- Final score and performance feedback
- Keyboard support using Enter to submit answers
- Escape key and outside-click support for closing the quiz
- Responsive design for desktop, tablet, and mobile screens
- Interactive geometry diagrams using SVG
- Different question types within each math topic
